صفحة د. محمد راضي — نسخة GitHub وVercel

1. فك ضغط الملف على الكمبيوتر.
2. ارفع index.html وstyle.css وapp.js ومجلد assets إلى جذر مستودع GitHub.
3. استورد المستودع في Vercel واختر Other، دون أمر Build. مجلد الجذر ./ ومجلد الإخراج . إن طلبه الإعداد.
4. انشر الموقع.

الملف يحتوي على الشعار المتحرك والصورة والخريطة وخبرة أكثر من ٢٠ عامًا ونموذج واتساب 0537008898.
لم يتم تضمين مستودع Git أو بيانات الوصول.
بعد تحديد الدومين النهائي، أضف canonical بعنوان الموقع واستبدل og:image برابط مطلق للصورة على نفس الدومين لتحسين مشاركة الرابط.
لا توجد أدوات تحليلات متصلة حاليًا. أحداث التواصل مجهزة في dataLayer فقط، ولا تعني حجزًا مؤكدًا.
